Ghid CCNA

Comenzile Cisco IOS de bază (fișă pentru CCNA)

Echipa Routerel· Actualizat: 5 noiembrie 2026· 13 min de citit

Fișa asta adună comenzile Cisco IOS de care ai nevoie zilnic în laborator și la examen: cum te miști prin modurile CLI, cum configurezi de la zero un router sau un switch, cum pui parole și SSH, cum configurezi interfețele, cum salvezi și ce îți arată fiecare comandă show. E gândită să fie parcursă rapid: tabele, exemple scurte, explicații doar unde contează.

În cursurile CCNA v8 de la Networking Academy, comenzile de bază se învață în CCNA 1 · ITN: configurarea inițială în modulul 7, securizarea accesului (parole, SSH) în modulul 16, testarea conectivității în modulul 13 și depanarea în modulul 17. În CCNA 2 · IEN, modulul 1 reia administrarea switch-urilor și a routerelor la un nivel mai avansat.

Toate exemplele folosesc nume de interfețe de pe echipamente des întâlnite în laboratoare (de exemplu GigabitEthernet0/0/0 pe routere și FastEthernet0/1 pe switch-uri). Pe echipamentul tău numerotarea poate diferi; verifică-o cu show ip interface brief.

Modurile CLI și prompturile

Promptul îți spune mereu unde ești. E primul lucru la care te uiți când o comandă nu merge.

glisează

Mod Prompt Cum intri Ce poți face
User EXEC R1> te conectezi (consolă, SSH) câteva comenzi show, ping
Privileged EXEC R1# enable toate comenzile show, copy, reload, debug
Global configuration R1(config)# configure terminal setări pentru tot echipamentul
Interface R1(config-if)# interface GigabitEthernet0/0/0 setările unei interfețe
Subinterface R1(config-subif)# interface GigabitEthernet0/0/0.10 subinterfețe (de exemplu pentru VLAN-uri)
Interface range S1(config-if-range)# interface range FastEthernet0/1 - 10 mai multe porturi deodată
Line R1(config-line)# line console 0 sau line vty 0 4 accesul prin consolă sau de la distanță
VLAN S1(config-vlan)# vlan 10 numele și setările unui VLAN
Router R1(config-router)# router ospf 1 protocolul de rutare

Cum te miști între moduri

glisează

Comandă / tastă Efect
enable din user EXEC în privileged EXEC
disable înapoi în user EXEC
configure terminal (conf t) intri în configurarea globală
exit urci un singur nivel (din config-if în config)
end sau Ctrl+Z sari direct în privileged EXEC, din orice mod de configurare
do <comandă> rulezi o comandă EXEC din configurare: do show ip interface brief

Ajutorul și prescurtările

  • ? afișează ce poți scrie în locul acela: show ? listează toate variantele, cl? listează comenzile care încep cu „cl”.
  • <cr> în lista de ajutor înseamnă „comanda e completă, poți apăsa Enter”.
  • Tab completează un cuvânt început, dacă e unic.
  • Orice comandă poate fi prescurtată cât timp rămâne unică: sh ip int br = show ip interface brief, copy run start = copy running-config startup-config, no shut = no shutdown.
  • no în fața unei comenzi o anulează: no shutdown, no ip address, no vlan 20.

Mesajele de eroare pe care le vei vedea des:

glisează

Mesaj Ce înseamnă
% Ambiguous command prescurtarea se potrivește cu mai multe comenzi; mai scrie câteva litere
% Incomplete command. lipsește un argument; pune ? după comandă
% Invalid input detected at '^' marker. ai greșit acolo unde arată ^ (sau ești în modul greșit)

Unde stă configurația

glisează

Memorie Ce conține Se pierde la oprire?
RAM configurația activă (running-config), tabelele (ARP, rutare) da
NVRAM configurația salvată (startup-config) nu
Flash sistemul de operare IOS (și, la switch-uri, vlan.dat) nu
ROM programul de pornire și diagnosticare nu

Tot ce scrii în modul de configurare se aplică imediat, în running-config. Dacă nu salvezi, la repornire pierzi totul.

Configurarea de bază a unui router sau switch

O configurare inițială tipică (înlocuiește textele scrise cu majuscule cu valorile tale):

Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# no ip domain-lookup
R1(config)# enable secret PAROLA_ENABLE
R1(config)# line console 0
R1(config-line)# password PAROLA_CONSOLA
R1(config-line)# login
R1(config-line)# logging synchronous
R1(config-line)# exec-timeout 5 0
R1(config-line)# exit
R1(config)# service password-encryption
R1(config)# security passwords min-length 10
R1(config)# banner motd # Acces permis doar persoanelor autorizate. #
R1(config)# end
R1# copy running-config startup-config

glisează

Comandă De ce o folosești
hostname R1 numele echipamentului; apare în prompt și e necesar pentru SSH
no ip domain-lookup o comandă scrisă greșit nu mai e tratată ca nume de rezolvat prin DNS (altfel aștepți zeci de secunde)
enable secret ... parola pentru modul privilegiat, stocată ca hash
line console 0 + password + login parola pe portul de consolă; fără login, parola nu e cerută
logging synchronous mesajele de sistem nu-ți mai rup comanda pe care o scrii
exec-timeout 5 0 deconectare după 5 minute și 0 secunde de inactivitate
service password-encryption ascunde parolele în clar din configurație (criptare slabă, tip 7)
security passwords min-length 10 lungimea minimă pentru parolele configurate de acum înainte
banner motd # ... # mesajul afișat la conectare; # e delimitatorul și nu trebuie să apară în text

Două lucruri pe care le întreabă des examenul:

  • enable secret bate enable password. Dacă le ai pe amândouă, se folosește doar enable secret. Folosește-l mereu pe el.
  • service password-encryption nu e securitate adevărată. Criptarea de tip 7 se decriptează în câteva secunde; doar te ferește de privirile de peste umăr.

Pentru a bloca încercările repetate de ghicire a parolei: login block-for 120 attempts 3 within 60 (blochează autentificarea 120 de secunde după 3 încercări eșuate în 60 de secunde).

Accesul de la distanță prin SSH

Telnet trimite totul în clar, inclusiv parola. SSH criptează sesiunea și e singura variantă acceptabilă azi. Pașii, în ordine:

R1(config)# ip domain-name exemplu.local
R1(config)# crypto key generate rsa general-keys modulus 2048
R1(config)# ip ssh version 2
R1(config)# username admin privilege 15 secret PAROLA_ADMIN
R1(config)# line vty 0 4
R1(config-line)# transport input ssh
R1(config-line)# login local
R1(config-line)# exec-timeout 10 0
R1(config-line)# end
R1# copy running-config startup-config

glisează

Pas Detaliu important
hostname (dacă nu l-ai setat deja) trebuie să fie diferit de cel implicit; cheile RSA se generează doar așa
ip domain-name numele de domeniu intră în numele cheii; pe IOS XE recent comanda apare în configurație ca ip domain name; ambele forme sunt acceptate (la fel no ip domain lookup)
crypto key generate rsa ... modulus 2048 creează cheile și pornește serverul SSH; SSH v2 cere cel puțin 768 de biți pe IOS clasic; azi folosești minimum 2048
ip ssh version 2 dezactivează versiunea 1, veche și nesigură
username ... secret ... utilizatorul local, cu parola stocată ca hash
transport input ssh pe liniile vty se acceptă doar SSH, nu și Telnet
login local autentificarea se face cu utilizatorii locali, nu cu parola liniei

Pe switch-uri, liniile vty sunt de obicei 16, deci scrii line vty 0 15. Pe routere, numărul lor diferă de la model la model; line vty 0 4 e varianta clasică. Câte linii are echipamentul tău vezi cu line vty 0 ? sau show running-config | section line vty; configurează-le pe toate.

Verificarea: show ip ssh (versiunea și setările SSH) și show ssh (sesiunile conectate acum). De pe alt echipament Cisco te conectezi cu ssh -l admin 192.168.1.1.

Adresa de management a unui switch

Un switch Layer 2 nu are adrese IP pe porturi. Ca să-l administrezi de la distanță, îi dai o adresă pe o interfață virtuală (SVI) și un gateway:

S1(config)# interface vlan 99
S1(config-if)# ip address 192.168.99.11 255.255.255.0
S1(config-if)# no shutdown
S1(config-if)# exit
S1(config)# ip default-gateway 192.168.99.1

Despre VLAN-uri, porturi access și trunk ai un ghid separat: VLAN-uri și trunk-uri explicate.

Configurarea interfețelor

R1(config)# interface GigabitEthernet0/0/0
R1(config-if)# description Spre LAN-ul de la etajul 1
R1(config-if)# ip address 192.168.10.1 255.255.255.0
R1(config-if)# ipv6 address 2001:db8:acad:10::1/64
R1(config-if)# ipv6 address fe80::1 link-local
R1(config-if)# no shutdown
R1(config-if)# exit
R1(config)# ipv6 unicast-routing

glisează

Comandă Efect
description ... o notă pentru oameni; nu schimbă funcționarea
ip address <adresă> <mască> adresa IPv4; masca se scrie în format zecimal, nu cu prefix
ipv6 address <adresă>/<prefix> adresa IPv6; aici se scrie cu prefix
ipv6 address fe80::1 link-local înlocuiește adresa link-local generată automat
no shutdown pornește interfața
shutdown oprește interfața
ipv6 unicast-routing (globală) pornește rutarea IPv6 pe router

Regula care prinde mulți începători: interfețele routerelor sunt oprite implicit și au nevoie de no shutdown. Porturile switch-urilor sunt pornite implicit. Pentru adresele IPv6 și prescurtarea lor, vezi adresele IPv6 explicate; pentru măști și subrețele IPv4, subnetting pas cu pas.

Salvarea și gestionarea configurației

glisează

Comandă Ce face
copy running-config startup-config salvează configurația activă în NVRAM
write memory (sau wr) același efect, forma veche, încă acceptată
show running-config configurația activă
show startup-config configurația salvată
erase startup-config sau write erase șterge configurația salvată (după reload, echipamentul pornește gol)
reload repornește echipamentul
copy running-config tftp: copie de siguranță pe un server TFTP
copy startup-config running-config combină configurația salvată cu cea activă; nu o înlocuiește

Ai stricat ceva și nu ai salvat? reload fără să salvezi (răspunzi „no” când te întreabă dacă salvezi) te întoarce la ultima configurație salvată. Pe un switch, VLAN-urile stau în vlan.dat, deci pentru o resetare completă ștergi și acel fișier: delete flash:vlan.dat.

Comenzile show: fișa rapidă

glisează

Comandă Ce îți arată
show version versiunea IOS, timpul de funcționare, modelul, memoria, interfețele, registrul de configurare
show running-config configurația activă
show startup-config configurația salvată
show ip interface brief toate interfețele, adresa IPv4 și starea (Status / Protocol), pe câte un rând
show ipv6 interface brief același lucru pentru IPv6, cu adresele link-local și globale
show interfaces g0/0/0 detalii de nivel 1 și 2: MAC, viteză, duplex, MTU, erori, CRC, coliziuni
show ip interface g0/0/0 detalii de nivel 3: adresa, ACL-urile aplicate și alte setări IP
show ip route tabela de rutare IPv4 (C = conectată, L = adresa locală, S = statică, O = OSPF)
show ipv6 route tabela de rutare IPv6
show arp (sau show ip arp) tabela ARP: IP → MAC
show mac address-table (switch) adresele MAC învățate, pe port și pe VLAN
show vlan brief (switch) VLAN-urile și porturile access din fiecare
show interfaces trunk (switch) trunk-urile, native VLAN, VLAN-urile permise
show cdp neighbors vecinii Cisco direct conectați: nume, port local, port la distanță, model
show cdp neighbors detail același lucru, plus adresele IP și versiunea IOS ale vecinilor
show lldp neighbors vecinii prin LLDP, protocolul standard (trebuie pornit cu lldp run)
show ip protocols protocoalele de rutare active și setările lor

show history ultimele comenzi scrise în sesiunea curentă
show users cine e conectat la echipament
show clock data și ora echipamentului
show flash: fișierele din memoria flash, inclusiv imaginea IOS
show ip ssh dacă SSH e activ și ce versiune folosește
show logging mesajele de sistem păstrate în memorie

Filtrarea ieșirii

Ieșirile lungi le filtrezi cu bara verticală:

glisează

Filtru Exemplu Efect
include show running-config | include hostname doar rândurile care conțin textul
exclude show ip interface brief | exclude unassigned ascunde rândurile care conțin textul
begin show running-config | begin line vty începe afișarea de la primul rând care conține textul

terminal length 0 oprește paginarea (--More--) pentru sesiunea curentă, util când copiezi o configurație întreagă.

Depanarea: ping, traceroute și starea interfețelor

ping

R1# ping 192.168.20.10
R1# ping 192.168.20.10 source GigabitEthernet0/0/0
R1# ping 192.168.20.10 repeat 100
R1# ping

Ultima formă, ping fără argumente, pornește ping-ul extins, care te întreabă pas cu pas destinația, numărul de packet-uri (pachete), dimensiunea și adresa sursă.

glisează

Simbol Înseamnă
! a venit răspuns
. a expirat timpul, niciun răspuns
U un router de pe drum a răspuns că destinația nu poate fi atinsă

Primul ping spre o destinație nouă pierde adesea primul packet (.!!!!): echipamentul așteaptă întâi răspunsul ARP. E normal.

traceroute

traceroute 203.0.113.10 arată fiecare router de pe drum și timpul până la el. Un * înseamnă că acel hop nu a răspuns în timp. Pe Windows, comanda echivalentă e tracert. Locul unde se oprește lista e un indiciu bun pentru unde e problema.

Starea interfețelor (show ip interface brief)

glisează

Status Protocol Ce înseamnă Ce faci
up up totul e în regulă nimic
administratively down down interfața are shutdown no shutdown
down down problemă fizică: cablu deconectat sau defect, celălalt capăt oprit verifici cablul și celălalt capăt
up down problemă de nivel 2 (mai ales pe legături seriale: încapsulare diferită la cele două capete, lipsa clock rate pe capătul DCE) verifici configurația ambelor capete

În show interfaces, contoarele ajută și ele: multe erori CRC indică un cablu defect sau interferențe, iar coliziunile întârziate (late collisions) indică de obicei o nepotrivire de duplex. Cu clear counters le aduci la zero și vezi dacă mai cresc.

debug (cu grijă)

R1# terminal monitor
R1# debug ip icmp
R1# undebug all

debug afișează în timp real ce face echipamentul, dar consumă procesor. Pe un echipament în producție poate încetini sau chiar bloca totul. Folosește-l cât mai țintit, cât mai scurt și oprește-l mereu cu undebug all (sau no debug all). terminal monitor e necesar ca să vezi mesajele când ești conectat prin SSH, nu pe consolă. show debugging îți arată ce debug-uri sunt active.

Cum le înveți fără să le tocești

  • Configurează de la zero, din memorie, un router și un switch: hostname, parole, SSH, interfețe, salvare. Repetă până îți ia sub 10 minute.
  • După fiecare comandă de configurare, verifică cu o comandă show. Așa înveți perechile: ip address ↔ show ip interface brief, vlan ↔ show vlan brief, SSH ↔ show ip ssh.
  • Strică intenționat, apoi repară: un shutdown uitat, o mască greșită, login lipsă pe consolă.
  • Leagă comenzile de straturi: show interfaces e nivelul 1–2, show ip route e nivelul 3. Vezi modelul OSI vs TCP/IP.

Descoperă aplicația

Întrebări frecvente

Care e diferența dintre running-config și startup-config?

Running-config e configurația activă, din RAM; se pierde la repornire dacă nu o salvezi. Startup-config e configurația salvată în NVRAM, încărcată la pornire. Le sincronizezi cu copy running-config startup-config.

Care e diferența dintre enable password și enable secret?

Ambele protejează accesul în modul privilegiat, dar enable secret stochează parola ca hash, care nu poate fi citit înapoi, iar enable password o păstrează în clar sau cu o criptare slabă. Dacă sunt configurate amândouă, se folosește enable secret.

Ce trebuie să configurez ca să am acces SSH la un router Cisco?

Un hostname diferit de cel implicit, un nume de domeniu (ip domain-name), o pereche de chei RSA (crypto key generate rsa), un utilizator local (username ... secret ...), apoi pe liniile vty: transport input ssh și login local. Recomandat și ip ssh version 2.

Ce face service password-encryption?

Ascunde parolele scrise în clar în configurație (de exemplu cele de pe consolă și vty) cu o criptare slabă, de tip 7. Te ferește de cineva care se uită peste umăr, dar parolele pot fi decriptate ușor, deci nu înlocuiește enable secret și utilizatorii cu secret.

Cum ies rapid din modul de configurare?

Cu end sau Ctrl+Z ajungi direct în modul privileged EXEC (promptul cu #). Comanda exit urcă doar un nivel.

Cum rulez o comandă show din modul de configurare?

Pui do în fața ei, de exemplu do show ip interface brief. Așa nu mai ieși și reintri în configurare. Pentru planul complet de pregătire, vezi ghidul despre CCNA.
