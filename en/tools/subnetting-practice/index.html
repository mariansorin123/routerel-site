How it works

  1. Pick a level (Easy, Medium or Hard) and, if you like, a single exercise type.
  2. Read the address or task and type your answer (or choose Yes / No).
  3. Press Check (with Yes / No the answer is checked right away): you see at once whether it's right, plus the correct answer.
  4. Read the step-by-step working with the block-size method, then move to the next exercise.

The block-size method, with /20, /22 and /30 examples, VLSM and practice exercises with answers, is explained in the guide Subnetting explained step by step.

Frequently asked questions

How many exercises are there?

Unlimited. Each one is generated on the spot with realistic private or public addresses, and the same question never comes up twice in a row.

What kinds of questions are there?

Network address, broadcast address, first and last host, number of hosts, mask for a prefix, next subnet, whether an address can be assigned to a host, mask for N hosts, and number of subnets.

How do I type my answer?

Addresses with dots (for example 192.168.1.64), numbers with or without thousand separators, and for “mask for N hosts” either the prefix (/26) or the mask (255.255.255.192).

Which method does the working use?

The block-size (“magic number”) method: block size = 256 minus the mask value in the interesting octet, then the multiples of the block give the network, broadcast and hosts.

Is my score saved?

No. The score and streak last only while the page is open; no account is needed and nothing is sent anywhere.
